# Six Words, One Story

Entry for the [make.fun Six Words, One Story](https://make.fun/r/41fw6r6c) competition (`u-deranalabs-six-words-one-story-f982e410`).

## Usage

```bash
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Writes a deterministic, UTF-8, six-word story (within the 1–60 character gate) to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt`.
